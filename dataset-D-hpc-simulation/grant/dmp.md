> This DMP follows the Horizon Europe DMP template. It covers all ten DC projects. DC-specific details are in Annex A.

## 1. Data summary

FLOWNET-DN will generate numerical simulation data (velocity and density fields, force histories, convergence logs), research software (the FLOWNET LBM toolkit and scripts), and processed benchmark results. Data are generated to validate LBM methods and to build an open benchmark database. Inputs are case definitions and meshes generated by the DCs, with **only open-source or consortium-generated inputs**. No third-party restricted data are reused.

Expected volumes: up to 1 TB per DC in total. **DC7 (Northmoor) expects about 200 GB** of simulation output.

## 2. FAIR data

### 2.1 Making data findable, including provisions for metadata

All datasets will receive a DOI through Zenodo, in the FLOWNET-DN community. Metadata will follow the DataCite schema, with keywords from a FLOWNET vocabulary (to be developed).

### 2.2 Making data accessible

Data will be "as open as possible, as closed as necessary". **All simulation output will be deposited in full on Zenodo** at the end of each DC project. No embargo is expected.

### 2.3 Making data interoperable

Fields will be stored in HDF5 or VTK. Tabular results (force coefficients, residual histories) will be shared as CSV.

### 2.4 Increase data reuse

Processed results, including force coefficients, residual histories and derived quantities such as the Strouhal number, will be shared as CSV under **CC BY 4.0** via Zenodo. **All software developed by DCs will be released under the MIT licence** on GitHub and archived on Zenodo. Every workflow will be containerised (Apptainer) with a pinned environment, so that each published result can be reproduced from the deposited code and inputs.

## 3. Other research outputs

Training materials from network schools: CC BY 4.0.

## 4. Allocation of resources

Data management costs are covered by each beneficiary's management costs. Each beneficiary appoints a data contact. Long-term preservation is through Zenodo at no cost.

## 5. Data security

Working data are kept on each beneficiary's HPC scratch storage during runs. **Scratch outputs are synchronised weekly to backed-up project storage** at the host institution. Zenodo provides long-term storage.

## 6. Ethics

No personal or sensitive data are generated in any DC project. No ethics issues are foreseen.
