## 10. Software

10.1 Software developed in the project will be released as open source. The default licence is **MIT**.

10.2 Where software incorporates third-party code whose licence is not compatible with the default licence, the developing party must notify the **Software Board** before release. The Software Board decides the licence for the release, consistent with the third-party terms.

10.3 No party may release software that includes another party's background without that party's written agreement.
