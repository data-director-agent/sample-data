# Dataset A: Hallam Moor sensors

Environmental science. Six moorland logger nodes, CSV, XLSX, text and R. All data, people and organisations are synthetic.

- `HallamMoor_loggers/` is the folder to give to the agent, as if you had inherited it.
- `crib-sheet.md` lists the planted problems, the true answers and the points where the agent should stop. Open it after the exercise.

Planted traps: time zone, unit and missing-code changes, a sensitive location, third-party licence.
