# Dataset E: NHS staff interviews on remote working

Social sciences and health services research. Thirteen files: text documents, five transcript excerpts, two CSVs and some leftovers. All data, people, places and events are synthetic.

- `NHS_remote_working_PhD/`: the dataset folder.

## Context

- **Researcher:** a PhD student with 25 transcribed interviews with NHS clinical staff about remote and flexible working and well-being.
- **Funder:** UKRI doctoral studentship. The funder expects data to be shared.
- **Institution:** the researcher's own (fictional Example University).
- **Plan:** deposit the transcripts in a national data archive.

The researcher, institution and trust are fictional. The funder and archives are real.
