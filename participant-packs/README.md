# Participant packs

One zip per dataset, each holding the inherited folder, a short `README.md` and the `crib-sheet.md`. Participants should open the crib sheet only after the exercise.

| Zip | Dataset |
|---|---|
| `Dataset_A_Hallam_Moor_sensors.zip` | A: moorland sensors |
| `Dataset_B_Perovskite_XRD_SEM.zip` | B: perovskite XRD and SEM |
| `Dataset_C_Community_survey.zip` | C: community survey |
| `Dataset_D_Cylinder_flow_HPC.zip` | D: cylinder flow simulation |

`Repository_scenario_cards.md` is the participant version of the scenario cards.
